## Risk Factors

### Downside Risks

| Risk | Impact | Mitigation |
|------|--------|------------|
| Low TPC clients | Partner earnings below target | Qualify referrals upfront |
| Single-project clients | Minimal ongoing earnings | Emphasize relationship value |
| Client churn | Truncated earnings | Focus on quality referrals |
| Economic downturn | Reduced project volume | Build diversified partner base |

### Upside Opportunities

| Opportunity | Impact | How to Capture |
|-------------|--------|----------------|
| High-value clients | 2-3x earnings | Target enterprise referrals |
| Multi-project clients | Compounding returns | Incentivize relationship depth |
| Long retention | Extended earnings | Reward loyalty |
| Word-of-mouth | Network effects | Partner tiering system |

## Recommendations by Scenario

### If Pessimistic Case Dominates (>40% likelihood)

1. Consider higher payout rates (40-45%)
2. Add signing bonus for first referral
3. Implement tiered rewards for multiple referrals
4. Focus on smaller partner pool with higher engagement

### If Base Case Expected (50%+ likelihood)

1. Proceed with recommended 35%/15% structure
2. Monitor actual TPC and project frequency
3. Review after 12 months with real data
4. Adjust Year 4+ rates based on retention

### If Optimistic Case Likely (>30% likelihood)

1. Could reduce rates slightly (30%/10%)
2. Add performance bonuses for top partners
3. Invest in partner portal/tracking
4. Expand partner recruitment aggressively
